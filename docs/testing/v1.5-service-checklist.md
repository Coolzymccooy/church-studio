# v1.5 test-service checklist

Run this once on the real church setup before relying on v1.5 on a Sunday. Do it mid-week and allow about 90 minutes.

For each item, tick the box or write what happened. Anything that fails goes into a GitHub issue with a screenshot.

## 0. Setup
- [ ] Install TIWATON AI Studio **v1.5.0** on the sound PC. Open it and confirm the landing page shows v1.5.0.
- [ ] Install the free **NDI Runtime** (https://ndi.video/tools) on the sound PC and on the AetherCast PC.
- [ ] Install **OBS 30.2 or newer**. Turn on Tools → WebSocket Server Settings and note the password.
- [ ] Use Lumina with the **test account** (not the church's real account).
- [ ] Save three mixer scenes named **Worship**, **Sermon** and **Walk-in**, set up so they sound clearly different.

## 1. Engine and mixer
- [ ] Start the engine with the real interface. The meters move on every strip.
- [ ] Run for 10 minutes. CPU load is stable, and dropped samples stay at 0 or close to it.
- [ ] Loading each scene changes faders and mutes as expected.

## 2. NDI® out (to AetherCast)
- [ ] In the output router, tick **Send to NDI®** for Stream. Restart the engine when asked.
- [ ] On the AetherCast PC, **TIWATON Studio (Stream)** appears in the NDI source list.
- [ ] Route it in AetherCast. The audio is clean, in sync, not doubled, and left/right are correct.
- [ ] Leave it running for **60 minutes**. There are no clicks or dropouts and the delay doesn't creep up.

## 3. NDI® in (from AetherCast or Lumina)
- [ ] Open **NDI® inputs**. The other machines' NDI sources are listed, and this PC's own outputs are greyed out.
- [ ] Tick one source and restart the engine. A new strip named after the source appears with its fader down.
- [ ] Raise the fader. The audio is clean, and the drift and underrun counters stay flat for 30 minutes.
- [ ] Untick the source and restart. The strip is gone, and no other strip has jumped to a loud level.

## 4. OBS
- [ ] Tools → OBS Studio…: connect with the host, port and password. The status pill shows Connected.
- [ ] The stream and record state match OBS. Start and stop a **recording** from the Studio (don't go live).
- [ ] Close OBS. The pill shows disconnected. Reopen OBS. It reconnects by itself and the mixer was never interrupted.
- [ ] Scene link: map Worship → an OBS scene. Loading Worship in the Studio switches OBS to it. Switching OBS back does not ping-pong.

## 5. Tiwaton Link (Lumina → audio scenes)
- [ ] Tools → Lumina Link…: turn it on and copy the URL and token.
- [ ] In Lumina, open Connect → TIWATON, paste the URL and token, and click **Check now**. It shows connected.
- [ ] Go live in Lumina and step through a song, then scripture, then a countdown. The Studio loads Worship, then Sermon, then Walk-in within about 2 seconds of each change.
- [ ] Flick quickly through 5 slides. The mix does not flap; it switches once.
- [ ] The activity log lists each change, and **Undo** restores the previous scene.
- [ ] Pause automation. Slide changes no longer change the mix.
- [ ] Close the Studio. Lumina shows "Studio not running", and AetherCast is unaffected.

## 6. Sign-off
